# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3   | :x:                |

## Reporting a Vulnerability

We take the security of `hnf1b-db` seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, report it via:
1. **GitHub Private Vulnerability Reporting**: Submit an advisory via the [Security Advisories](https://github.com/berntpopp/hnf1b-db/security/advisories/new) tab.
2. **Direct Email**: Email Bernt Popp at `bernt.popp@gmail.com`.

### What to Include
- Description of the vulnerability and potential impact.
- Steps to reproduce or proof-of-concept code.
- Any suggested remediations if available.

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- We will provide regular updates on triage and mitigation progress.
- Once fixed, a coordinated disclosure date will be agreed upon.
